本地变声 · 发布候选（仅公开产物）

启动（只绑定本机回环）：
  python -m http.server 8000 --bind 127.0.0.1 --directory .

然后打开： http://127.0.0.1:8000/app/index.html?mobile=1

iPhone 首次打开需要可信 HTTPS 静态站点，入口为 app/index.html?mobile=1。
将 app/、vendor/ 与 offline-worker.js 放在同一个站点目录，保持原目录层级。
打开后点「保存离线页面」，然后从「我的 iPhone」选择五个模型和参考包。
建议先以飞行模式重开同一入口，并用 1 秒以内录音验证转换与 WAV 下载。

说明：
- 这个目录里**没有**模型权重（.onnx），也**没有**参考音色包。
  五个模型文件和一个 seed-reference/v1 JSON 参考包需要使用者自己在本机选择；
  页面不会下载、上传、缓存它们，也不提供「默认音色」。
  缺少这两类文件时，页面会如实禁用「开始变声」，它不是可用的变声器。
- vendor/ 是 ONNX Runtime Web 1.22.0。许可证和上游第三方声明分别见 LICENSE 和 ThirdPartyNotices.txt。
- 手机候选可转换最长 5 秒的音频，每次录音最多 3 秒。页面离线保存只缓存前端和运行库。
- 默认入口仍是固定窗口：约 2.78 秒输入生成约 0.26 秒片段。
- 发布构建使用严格白名单（.html/.css/.js/.mjs/.wasm + LICENSE），
  任何音频、模型权重、参考特征、测试与证据文件都默认拒绝，不会被误打包。
- 没有广告、统计、第三方脚本或远程日志；CSP 只允许同源资源。
- 桌面浏览器/Node 已跑通链路，但**尚未在 iPhone Safari 真机验证**内存、耗时、发热与音质。
