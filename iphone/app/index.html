手机本地变声 · 第一项

本地音频与变声入口

这一版已经把本机随包的 ONNX Runtime Web 与固定窗口推理链路接进页面：音频输入、解码、 单声道处理、WAV 导出都在本机内存里完成。 但页面本身不含五个模型权重，也不含参考音色包——这两样要你自己在本机选择； 没有它们时「开始变声」保持禁用，页面不会给你假的变声结果。

音频只在本机内存里：不上传、不写本地存储，页面自身不联网。所有播放和录音都要你自己点。 若本机没有随包运行时，页面会显示「完整本地推理引擎尚未接入」并禁用变声。

当前限制：一次只处理一个固定窗口（约 2.78 秒输入 → 约 0.26 秒片段），不是整句转换、不是实时； 整句多块拼接尚未开放；桌面浏览器与 Node 已跑通链路，但尚未在 iPhone Safari 真机验证 内存、耗时、发热与音质。本页不提供「默认音色」，参考包属于私人数据。
