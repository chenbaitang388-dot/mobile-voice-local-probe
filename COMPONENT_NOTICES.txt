not a person's custom voice and not a complete voice converter:
  component-models/lr.onnx  - fixed 38-frame input / 67-frame output regulator
  component-models/dit.onnx - one DiT estimator call, synthetic 16-frame

PRIVACY / SCOPE
No custom voice recording, fine-tune, speaker embedding or actual 516-frame
private reference is included. Test reference/style/features are synthetic.
The graphs were inspected recursively for doc_string, metadata_props and all
protobuf text fields; neither original graph contained private path strings.
Weights and computation were not changed by that inspection. All browser
input and inference remain local; only public static files are downloaded.
Passing these fixed components does not establish full iPhone voice conversion,
real-time operation, voice quality or continuous streaming compatibility.
